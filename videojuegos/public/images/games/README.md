# Imágenes de Videojuegos

Esta carpeta contiene las imágenes de los videojuegos clásicos.

## Imágenes necesarias:

1. **mario.jpg** - Super Mario Bros
2. **zelda.jpg** - The Legend of Zelda
3. **pacman.jpg** - Pac-Man
4. **sonic.jpg** - Sonic the Hedgehog
5. **streetfighter.jpg** - Street Fighter II
6. **tetris.jpg** - Tetris

## Recomendaciones:

- Formato: JPG o PNG
- Tamaño recomendado: 800x600px o similar (ratio 4:3)
- Peso máximo: 500KB por imagen
- Las imágenes deben ser de buena calidad y representativas del juego

## Fuentes sugeridas para imágenes:

- Capturas de pantalla del juego
- Portadas oficiales
- Arte promocional
- Sitios de dominio público como Wikimedia Commons

**Nota:** Asegúrate de tener los derechos o usar imágenes de dominio público.
